# Adib Harith — portfolio

Personal portfolio site. One static page, no build step.

- `index.html` — the whole site (HTML, CSS and a little JS for the clock and pixel art)

Featured: [Rakan AI](https://rakanai.vercel.app), [Sayajual](https://sayajual.xyz), Hermes, [SFX Forge](https://sfxforge.vercel.app), The Million Pixels, Sprite Forge.

Deploy anywhere that serves static files (Vercel: import the repo, framework preset "Other").
